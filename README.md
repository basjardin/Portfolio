## 🚀 Installation locale
Si vous souhaitez explorer le code localement, suivez ces étapes :
1.  **Cloner le dépôt :**
```bash
    git clone [https://github.com/basjardin/Portfolio.git](https://github.com/basjardin/Portfolio.git)
```
2.  **Naviguer dans le dossier :**
```bash
    cd Portfolio
```
3.  **Ouvrir le projet :**
    Ouvrez simplement le fichier `index.html` dans votre navigateur ou utilisez l'extension *Live Server* sur VS Code.
